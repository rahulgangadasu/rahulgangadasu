# Hi there, I'm Rahul Gangadasu 👋

### Senior Software Application Developer | Angular | React | TypeScript | Java | Spring Boot | Microservices | AWS

I am a Senior Software Application Developer with experience in building scalable, secure, and enterprise-grade web applications across frontend, backend, cloud, and database layers.

My work focuses on developing modern single-page applications using Angular, React, TypeScript, RxJS, NgRx, Redux Toolkit, and reusable component-based UI architecture. I also have strong backend experience with Java, Spring Boot, RESTful APIs, Microservices, Hibernate, JDBC, SQL databases, and AWS cloud services.

I enjoy building clean, maintainable, and performance-focused applications that solve real business problems and support large-scale enterprise workflows.

---

## 🚀 What I Do

- **Frontend Engineering:** Build responsive, component-driven applications using Angular, React, TypeScript, RxJS, NgRx, Redux Toolkit, Angular Material, and Material UI.
- **Backend Development:** Design and develop RESTful APIs and microservices using Java, Spring Boot, Spring MVC, Hibernate, JDBC, and layered architecture.
- **Full-Stack Integration:** Connect Angular and React applications with secure backend services using REST APIs, JWT authentication, interceptors, and role-based access control.
- **Cloud & DevOps:** Work with AWS Lambda, EC2, S3, IAM, CloudWatch, DynamoDB, Docker, Jenkins, Maven, GitHub, and CI/CD pipelines.
- **Database Development:** Write and optimize SQL queries, stored procedures, triggers, functions, indexes, and database schemas using Oracle, SQL Server, MySQL, DynamoDB, and DB2.
- **Code Quality:** Focus on reusable components, clean architecture, unit testing, performance optimization, debugging, and Agile software delivery.
